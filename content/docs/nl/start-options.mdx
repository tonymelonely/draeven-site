`Start()` opent de gateway en beantwoordt interacties. <Explain topic="start-token">token</Explain> is verplicht.

<DocTour id="start-options" />

## De aanroep

```js
import { Start, guard, intentsFor } from "@draeven/core";

const bot = await Start({
  token: process.env.DISCORD_TOKEN,
  guildId: process.env.DISCORD_GUILD_ID,
  timeZone: "Europe/Amsterdam",
  presence: {
    status: "online",
    activity: { kind: "watching", text: "slash-commando's" },
  },
  intents: intentsFor("ready", "message"),
  events: "./dist/events",
  watch: process.env.NODE_ENV !== "production",
  guard: guard({ via: "console", of: "all" }),
  alone: "ask",
  autoDefer: true,
});
```

`commands` staat hier niet, dus Draeven leest `draeven.config.js` ([Config](/docs/config)). `events` staat hier als map, dus het `events`-veld uit de config wordt niet gebruikt. Laat `events` ook weg als het bestand al naar `./dist/events` wijst. `bot` is de [lopende bot-handle](/docs/bot-handle): `setPresence`, `send`, `stop` en `syncState`.

## Velden

| Veld | Wat het doet |
|------|----------------|
| <Explain topic="start-token">`token`</Explain> | Bot-token. Een lege token faalt al vóór de gateway opent. |
| <Explain topic="start-commands">`commands`</Explain> | Een array van commando's en menu's, een mappad of `URL`, of weglaten voor `draeven.config`. |
| <Explain topic="start-guildId">`guildId`</Explain> | Snowflake (1–20 cijfers). Commando's synchroniseren naar die guild. Weglaten maakt de volgende sync globaal. Guild-commando's die al staan, blijven in die server. |
| `timeZone` | IANA-naam, zoals `Europe/Amsterdam`. Gebruikt als `ctx.transcript()` er zelf geen meegeeft. |
| `presence` | Beginstatus en activiteit. Zie [Presence](/docs/presence). |
| <Explain topic="start-intents">`intents`</Explain> | Bitmask voor de gateway. Weggelaten is `0`. `intentsFor(...events)` vanuit eventnamen, of `intentBits(...names)` vanuit `intents.*`. |
| `events` | Een handlers-object, een map met gecompileerde modules, of weglaten om `events` uit `draeven.config` te gebruiken als dat veld er staat. `watch` herlaadt een map. Een inline object laadt geen `use()`. |
| `uses` | Extra duurzame `use()`-handlers in het geheugen. Wordt samengevoegd met map-`use()`-exports als `events` een pad is. Handig als `events` een inline object is (die vorm laadt nooit `use()` van schijf). |
| <Explain topic="start-watch">`watch`</Explain> | Standaard `false`. `true` herlaadt de commandomap en een events-map. Een array in het geheugen geeft een foutmelding. |
| `guard` | Het object dat `guard({...})` teruggeeft. Houdt het proces in leven en logt fouten. |
| <Explain topic="start-alone">`alone`</Explain> | Standaard `"ask"`. Ook `true` of `false`. Zie [Eén proces](/docs/alone). |
| <Explain topic="start-autoDefer">`autoDefer`</Explain> | Standaard **2000 ms**. `false` zet het uit. Een getal wordt geklemd op **500–2500** ms. |

Standaard als je ze weglaat: `intents` `0`, `watch` `false`, `alone` `"ask"`, `autoDefer` `2000`.

## Commando's en guild-sync

```js
await Start({
  token: process.env.DISCORD_TOKEN,
  commands: "./dist/commands",
  guildId: process.env.DISCORD_GUILD_ID,
});
```

Een string of `URL` is een map, net als het `commands`-pad in de config. Een array (`commands: [ping]`) is de lijst in het geheugen. Handig in een test. `watch: true` met die array geeft een foutmelding. Er is geen map.

Guild-sync toont nieuwe commando's binnen seconden in die server. Een globale sync (geen `guildId`) kan een uur duren. Geef de guild-id mee terwijl je bewerkt. Laat je hem later weg, dan registreert Draeven de globale lijst. Commando's die al op de guild staan, blijven daar. Discord verwijdert ze niet. Een id die geen snowflake is faalt bij het opstarten.

## Intents en events

`intentsFor("memberJoin", "message")` voegt de bits samen die die events nodig hebben, inclusief geprivilegieerde intents die Discord eist. `intentBits("guilds", "guildMessages")` doet een OR van benoemde vlaggen als je de namen al kent. Event-handlers hebben nog steeds de bits van hun naam nodig ([Events en intents](/docs/events-intents#intents)).

`events` als object staat vast voor het proces. Dat object laadt geen `use()`. Geef dan `uses: [letters]` mee voor duurzame handlers, of gebruik `events: "./dist/events"` zodat modules waarvan de exportnaam de eventnaam is samen met elke `use()` in die bestanden laden. Laat je `events` weg, dan gebruikt Draeven het `events`-pad uit `draeven.config.js` als het bestand er een zet. `watch: true` herlaadt die map als de bestanden veranderen. Map-`use()`-exports en `Start({ uses })` worden samengevoegd; een inline `press` wint nog steeds zolang dat antwoord onthouden wordt ([Press & submit](/docs/press-handlers#use)).

```js
import { Start, intentsFor } from "@draeven/core";
import { letters } from "./events/letters.js"; // een use()-export

await Start({
  token: process.env.DISCORD_TOKEN,
  commands: "./dist/commands",
  events: {
    ready: () => console.log("ready"),
  },
  uses: [letters],
  intents: intentsFor("ready"),
});
```

## Auto-defer

Discord geeft de handler ongeveer 3 seconden. De standaard <Explain topic="auto-defer">auto-defer</Explain> gaat af na 2 seconden, zodat een trage `await` alsnog bevestigt. `autoDefer: 800` stelt eerder uit. Waarden onder 500 worden 500. Waarden boven 2500 worden 2500. `autoDefer: false` op `Start` zet het uit voor elk commando. Eén commando kan nog `autoDefer: false` in zijn eigen metadata zetten ([Antwoorden](/docs/replies)).

<Note>
`timeZone` verandert `time()`-stempels in een embed niet. Die renderen in de zone van de lezer. De startzone is alleen de terugval voor een transcript.
</Note>

## Valkuilen

- `watch: true` met `commands: [ping]` geeft een foutmelding. Er is geen map om te bekijken.
- `guard` moet de waarde zijn die `guard()` teruggeeft. Een kaal `{ via, of }` geeft een foutmelding.
- `alone: "ask"` vraagt niets als stdin geen TTY is. Een levende tweede instantie faalt dan, tenzij je `alone: true` meegeeft.
- Een foute zonenaam (`"Amsterdam"`) faalt bij het opstarten. Gebruik `Europe/Amsterdam`.
